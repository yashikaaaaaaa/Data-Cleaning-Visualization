# 📊 Data Cleaning & Visualization Project

## 📌 Project Overview

This project focuses on cleaning, exploring, and visualizing the Sample Superstore dataset using Python.

The objective is to demonstrate practical data preprocessing techniques and create meaningful business insights through visualizations.
