# 📊 Data Cleaning & Visualization Project

## Project Overview

This project demonstrates data cleaning and visualization using the Sample Superstore dataset.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Tasks

- Imported the dataset
- Checked missing values
- Removed duplicate rows
- Generated descriptive statistics
- Created data visualizations

## Visualizations

- Sales by Category
- Sales by Region
- Profit Distribution
- Correlation Heatmap

## Files

- data_cleaning.ipynb
- Sample - Superstore.csv
- cleaned_superstore.csv
